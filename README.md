## 📋 About The Project

This project is a fully responsive business website designed and developed for a Kigali-based fitness gym. It showcases the gym's classes, trainers, working hours, location and contact information in a clean and modern design.

---

## ✨ Features

- ✅ Fully responsive design — works on all screen sizes
- ✅ Multi-page structure — Home, About and Classes pages
- ✅ Contact form with JavaScript input validation
- ✅ Google Maps integration showing gym location
- ✅ Social media links
- ✅ Trainer profiles with photos
- ✅ Class listings with pricing
- ✅ Working hours section
- ✅ Clean and modern UI with Poppins font

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Maps Embed API
- Unicons Icon Library
- Google Fonts (Poppins)

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
```bash
git clone https://github.com/kennedy193/fitness-website.git
```

2. Open the project folder
```bash
cd fitness-website
```

3. Open `index.html` in your browser

No dependencies or installations required — pure HTML, CSS and JavaScript.
